## Instalar librerías necesarias:
```
pip install --upgrade pip
pip install pandas numpy matplotlib seaborn scikit-learn scipy folium streamlit streamlit-folium
```
## Ejecución de la aplicación
### Desde la carpeta del proyecto, correr:
```
streamlit run app.py
```
Streamlit abrirá automáticamente un navegador con la app.
Si no se abre automáticamente, copia la URL que aparece en la terminal (por ejemplo http://localhost:8501) y pégala en tu navegador.
